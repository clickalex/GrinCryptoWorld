# 📱 GrinCryptoWorld Mobile (placeholder)

React Native (Expo) shell for the future mobile app. Screens planned:

- **Markets** — `/coins` equivalent with pull-to-refresh
- **Portfolio** — synced via `POST /api/tools/portfolio`
- **Alerts** — OneSignal push for price alerts (`/api/alerts`)
- **Blog & Glossary** — reading experience
- **WalletConnect v2 login** — mirroring the web MetaMask flow

The API contract is identical to the web frontend (`/api/*`).
